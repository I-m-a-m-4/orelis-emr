# **App Name**: MediTrack Pro

## Core Features:

- Role-Based Authentication: Secure login system with roles for Admin, Doctor, and Receptionist, using Firebase Authentication.
- Patient Management: Add, edit, delete, search, and view patient records. Store medical reports in Firebase Storage.
- Appointment Scheduling: Receptionists can schedule new appointments, and doctors can view their daily/weekly appointments. Appointment details are stored in Firestore.
- Appointment Reminders: Generate a short, personalized SMS text appointment reminders via EmailJS; an AI tool will make sure they go out 24 hours in advance of appointments but not during typical sleep hours.
- Doctor Dashboard: Securely access patient records, update notes, prescriptions, and follow-up dates.
- Admin Dashboard: Manage staff accounts (add/remove doctors, receptionists) and monitor hospital data overview.
- SEO-Optimized Landing Page: A public landing page to improve the site's visibility on search engines. A contact form enables user feedback which is sent with EmailJS.

## Style Guidelines:

- Primary color: Desaturated light blue (#ADD8E6) to convey a medical feel. The color relates to the requested light-blue color scheme as well as conveying tranquility and cleanliness, important in a medical setting.
- Background color: Very light grey (#F0F0F0) for a clean and neutral backdrop.
- Accent color: Muted dark blue (#4682B4) for emphasis on interactive elements and important information. This analogous color choice enhances usability and aesthetic harmony, differentiating key elements.
- Body and headline font: 'PT Sans', a humanist sans-serif that combines a modern look and a little warmth.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use simple, clear icons for navigation and data representation.
- Clean, responsive dashboard layout with side navigation and data tables.
- Subtle animations for transitions and feedback to enhance user experience.
